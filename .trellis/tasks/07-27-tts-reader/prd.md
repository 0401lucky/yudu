# TTS 听书

## Goal

用浏览器原生 SpeechSynthesis 实现听书：从当前位置开始按段朗读，正文跟随定位，无后端成本。

## Requirements

### 功能需求

1. **入口**：ReaderChrome 顶栏加「听书」按钮（PDF 书不显示）；点击进入听书状态，底部出现控制条。
2. **控制条**：播放/暂停、停止（退出听书）、语速（0.75 / 1 / 1.25 / 1.5 / 2）、音色选择（过滤 zh 语音，无中文音色时列全部并提示）。
3. **朗读行为**：
   - 从当前阅读位置所在段开始，按段落逐段朗读，读完自动下一段；章节读完自动进入下一章继续。
   - 当前朗读段落在正文中高亮（底色标识），并自动跟随：滚动模式滚到段落可见；翻页模式自动翻到该段所在页。
   - 暂停/继续保持在当前段；切章/手动跳转时从新位置重新开始。
4. **偏好记忆**：语速、音色 voiceURI 存 localStorage。
5. **退出**：离开阅读页、切书自动停止朗读（组件卸载清理）。

### 非功能需求

- 长段落切块朗读（约 ≤160 字符按标点切分），规避 Chrome 长 utterance 静默中断问题。
- `speechSynthesis.getVoices()` 异步就绪：监听 `voiceschanged`。
- 浏览器不支持 SpeechSynthesis 时按钮隐藏。
- 朗读文本取「渲染后纯文本」（与高亮/书签同一口径），markdown 书读渲染文本而非源码。

## Out of Scope

- 云端 TTS（付费语音）、后台锁屏播放、定时关闭、倍速以外的音调调节。
- PDF 听书。

## Acceptance Criteria

- [ ] txt/md/epub 书可从当前位置连续朗读并跨章；当前段有视觉标识且视口跟随。
- [ ] 播放/暂停/停止/语速/音色可用，偏好刷新后保留。
- [ ] 离开页面/切书后不再发声。
- [ ] 双阅读模式、双主题下控制条与段落标识正常。
- [ ] `pnpm typecheck && pnpm test` 通过（新增 hook 的纯逻辑如分段函数需单测）。
