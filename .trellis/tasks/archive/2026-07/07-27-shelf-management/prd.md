# 书架管理：排序分组批量操作

## Goal

书多了以后书架仍好用：支持排序、单层分组、多选批量删除与批量移动分组。

## Requirements

### 功能需求

1. **排序**：书架工具栏提供排序切换——最近阅读（默认，无阅读记录的排后面）/ 最近导入 / 书名（localeCompare zh）。选择记忆在 localStorage。
2. **分组**：单层分组（类似文件夹标签）。书可属于 0 或 1 个分组；工具栏显示「全部 + 各分组」筛选 tabs（含书数）；分组在移动书籍时即时新建（输入名称），空分组自动消失（无实体表）。
3. **多选模式**：进入管理模式后书卡变复选；支持全选；批量删除（二次确认，显示数量）；批量移动到分组 / 移出分组。
4. **云端同步**：分组是书的属性，存 D1，跨设备一致。
5. **BookSummary 扩展**：返回 `createdAt`、`lastReadAt`（无进度为 null）、`group`（无分组为 null），排序在前端做。

### 非功能需求

- 分组名 trim 后 1–30 字符；超限前端阻止、后端 400。
- 批量删除复用现有单本 DELETE 逐个执行（保留 R2 清理逻辑），前端串行调用并汇总失败项；不新增批量端点。

## Out of Scope

- 多级/嵌套分组、一书多标签。
- 拖拽排序、自定义手动顺序。
- 分组重命名（移动书籍即可达成，MVP 不做）。

## Acceptance Criteria

- [ ] 三种排序正确（最近阅读以 lastReadAt 降序，null 最后）。
- [ ] 新建分组、移动、筛选、跨设备可见；分组名非法后端 400。
- [ ] 多选批量删除/移动可用，删除有确认，部分失败有提示且列表状态正确。
- [ ] books 路由测试补充 group 相关用例（合法/非法/越权）。
- [ ] `pnpm typecheck && pnpm test` 通过。
