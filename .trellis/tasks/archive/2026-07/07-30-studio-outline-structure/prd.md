# 大纲与细纲结构化

## Goal

把创作台第 3、4 步（总大纲、分章细纲）从「一坨自由文本」改成结构化字段，让用户能定点修改、让下游生成拿到精确输入。沿用立项与人设两次改造已验证的模式：可选字段 + 按块解析 + 旧数据保留 + 折叠面板。

## Background / 现状问题

**总大纲**（`StudioWorkPage.tsx` outline 段）：`assets.outline` 是单个字符串，UI 是一个 `rows={16}` 的 textarea。提示词只说「写一份总大纲（起承转合、主线冲突、结局方向）」然后直接输出正文。

- 想改「结局方向」得在长文本里翻找
- 下游（细纲、正文）拿到整坨文本，AI 得自己从里面找信息
- AI 输出结构完全随机，有时给标题有时不给

**分章细纲**：`StudioChapterOutline = { index, title, summary }`，`summary` 是「节拍 / 冲突 / 钩子」揉成的一段话。

- 章末钩子是网文最关键的一环，却没有独立位置
- 几十章全部平铺展开，页面被拉得极长
- 正文生成时只能拿到一段混合摘要

## Requirements

### R1 总大纲八字段

`StudioAssets` 新增 `outlineDetail`，含 8 个可选字段：

| 字段 | 界面标签 | 含义 |
|---|---|---|
| `throughline` | 一句话主线 | 全书从头到尾在讲的那件事 |
| `setting` | 世界观设定 | 规则、时代、力量体系 |
| `conflict` | 核心冲突 | 主角要对抗什么，为什么绕不开 |
| `act1` | 起 · 开局 | 怎么把读者拽进故事 |
| `act2` | 承 · 发展 | 中段靠什么推进不塌 |
| `act3` | 转 · 高潮 | 最大的那次崩塌或翻盘 |
| `act4` | 合 · 结局 | 落在哪里 |
| `subplots` | 支线与伏笔 | 埋了什么，什么时候收 |

原 `outline: string` 保留装旧数据，界面上在结构化字段下方以「旧大纲」标注展示且可编辑。

### R2 分章细纲三字段

`StudioChapterOutline` 新增 3 个可选字段：

| 字段 | 界面标签 | 含义 |
|---|---|---|
| `conflict` | 本章冲突 | 这章的看点；没有就是水章 |
| `hook` | 章末钩子 | 让人点下一章的理由 |
| `characters` | 出场人物 | 谁在场，用于人设一致性 |

`summary`（本章梗概）保留为主字段，语义不变。

### R3 AI 按块生成

- 总大纲：AI 按「字段名：值」逐行输出 8 个字段，不再自由发挥。
- 分章细纲：AI 按块输出，一章一块，块内 `标题` / `梗概` / `冲突` / `钩子` / `人物` 各一行。
- 两者都要有退化路径：解析出 0 条时退回现有行为（大纲整段进 `outline` 字符串；细纲退回 `标题｜摘要` 行解析）。
- 解析失败报可读错误，不清空用户已有内容。

### R4 折叠面板 UI

- 总大纲：8 个字段依次展开（数量固定，不需要折叠），底部「旧大纲」区仅在非空时出现。
- 分章细纲：一章一张可折叠卡片，收起显示「第 N 章 · 标题」，展开看 4 个字段；新增章节默认展开。
- 细纲支持删除单章（与人设一致）。

### R5 下游打通

- `buildChapterOutlinesMessages`：拿到结构化大纲而非整坨文本。
- `buildChapterBodyMessages`：拿到结构化大纲 + 本章的冲突 / 钩子 / 出场人物。
- 结构化为空时回退用 `outline` 字符串，行为等同现在。

## Constraints

- 老作品数据必须可正常打开、编辑、保存；旧 `outline` 与旧 `summary` 内容不丢。
- 不改动立项 / 人设 / 正文三步的 UI。
- 不改动破限（18+）逻辑与提示词内容。
- `normalizeAssets` 是字段白名单，新字段必须同步补上（见 `.trellis/spec/api/backend/database-guidelines.md`）。
- 无 D1 迁移：新字段在 `studio_assets` JSON 内。
- 解析遵循 `.trellis/spec/web/frontend/quality-guidelines.md` 的创作台解析三条约定。

## Acceptance Criteria

- [ ] 「AI 生成总大纲」后 8 个字段各自被填上，可单独编辑
- [ ] 「AI 生成细纲」后每章有梗概、冲突、钩子、出场人物
- [ ] 细纲卡片默认收起显示「第 N 章 · 标题」，点击展开
- [ ] 「加一章细纲」新增的卡片默认展开
- [ ] 可删除单章细纲
- [ ] 改任一字段后保存，刷新页面正确回显
- [ ] 打开改造前的老作品，旧大纲出现在「旧大纲」区、旧 summary 仍在「本章梗概」里，均可编辑保存
- [ ] AI 回旧格式时退化解析生效，不报错
- [ ] AI 回完全不符格式时报错且不清空已有内容
- [ ] 生成正文时提示词含本章钩子与结构化大纲字段
- [ ] `parseOutlineDetailFromAi` / `parseChapterOutlinesFromAi` 单测覆盖：新格式、旧格式退化、字段缺失、乱答
- [ ] `normalizeAssets` 单测覆盖两组新字段保留
- [ ] `pnpm -r typecheck` 与 `pnpm -r test` 全绿
