# 文本高亮标注

## Goal

读者可以选中正文文本进行高亮标注,高亮云端同步、跨设备可见,在翻页与连续滚动两种模式下都能查看和管理。

## Requirements

### 功能需求

1. **创建高亮**:长按/鼠标选中正文文本后弹出操作气泡,可选高亮颜色(黄/绿/蓝 3 色)确认标注。
2. **渲染**:已有高亮在正文中以对应颜色底色显示;翻页模式与滚动模式渲染一致;plain 与 markdown 内容均支持。
3. **删除高亮**:点击已高亮文本弹出气泡,可删除(或改色)。
4. **高亮列表**:目录抽屉(TocDrawer)中新增"标注"分组或标签页,列出全书高亮(摘录文字 + 章节),点击跳转到对应位置,支持删除。
5. **云端同步**:高亮存 D1,按用户 + 书隔离;打开书时拉取本章/全书高亮;增删乐观更新、失败回滚提示(对标书签交互)。
6. **锚点**:`chapterIndex + startOffset + endOffset`(章内纯文本字符偏移)+ 摘录文本,单书上限 500 条,单条选区长度上限 1000 字符。

### 非功能需求

- 高亮渲染不破坏现有排版(翻页模式的多栏分页、字号行距调整)。
- 浏览器不支持 CSS Custom Highlight API 时优雅降级:正文不渲染底色,但列表、跳转、增删仍可用。

## Out of Scope

- 笔记/想法(给高亮附加文字评论)。
- 高亮导出、分享。
- PDF 高亮。
- 下划线等更多标注样式(仅底色高亮)。

## Acceptance Criteria

- [ ] 桌面端鼠标选词、移动端长按选词后可创建 3 色高亮,立即显示。
- [ ] 高亮在翻页/滚动两种模式、plain/markdown 两种内容下渲染位置正确。
- [ ] 点击高亮可删除、改色;目录抽屉可查看全书高亮列表并跳转/删除。
- [ ] 刷新页面、换设备(另一登录会话)后高亮仍在。
- [ ] 越权访问他人书籍的高亮接口返回 404;非法参数返回 400。
- [ ] 后端路由有测试覆盖(对标 bookmarks.test.ts 的用例面)。
- [ ] `pnpm -r lint && pnpm -r typecheck && pnpm -r test` 通过。
