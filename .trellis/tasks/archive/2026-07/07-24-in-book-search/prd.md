# 书内全文搜索

## Goal

在一本书内搜索关键词，结果带上下文摘录与高亮，点击跳转到对应章节页位置。

## Background

- 现状：阅读器无任何搜索能力。
- 章节正文存 R2（每章一个 JSON `{title,text}`），D1 `chapters` 表只有 `title` / `char_count` / `r2_key` 元数据——D1 无正文可查。
- 用户场景：小说回看名场面、md 笔记查关键词，都是"书内定位"需求。

## Requirements

1. 阅读器工具栏新增搜索入口，打开搜索抽屉/面板（交互模式与 TocDrawer 一致）。
2. 输入关键词（2–50 字符）回车或点按钮触发；大小写不敏感。
3. 结果列表：章节标题 + 含关键词的上下文摘录（关键词高亮）+ 章内位置；按章节顺序排列。
4. 点击结果跳转到目标章节，并落位到包含该关键词的页（按 charOffset 比例近似）。
5. 限流保护：每章最多 5 条命中、全书最多 50 条，超出提示"结果过多，请精确关键词"。
6. 仅支持文本类格式（txt / md / epub）；PDF 不在范围（入口对 PDF 隐藏）。
7. md 书直接搜源文文本（MVP 接受 Markdown 语法符号出现在摘录中）。

## Acceptance Criteria

- [ ] 多章含关键词的书能搜出跨章结果，摘录含高亮关键词。
- [ ] 点击结果跳到正确章节，且当前页包含关键词（允许 ±1 页近似偏差）。
- [ ] 关键词 < 2 字符提示不触发请求；无结果显示空态提示。
- [ ] 命中超限时截断并提示。
- [ ] 未登录 401；他人书籍 404。
- [ ] 一本 300+ 章的书搜索响应 < 3s（本地 dev 环境）。
- [ ] API 路由有 vitest 覆盖；`pnpm typecheck && pnpm test && pnpm build` 通过。

## Out of Scope

- 跨书全库搜索、正则/高级语法、搜索历史。
- PDF 文字搜索。
- 全文索引（FTS5）——量级不需要，见 design.md 选型。
