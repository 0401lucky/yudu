# 连续阅读与文本高亮(父任务)

## Goal

为雨读 Web 阅读器新增两项能力,提升沉浸阅读体验:

1. **连续阅读模式**:上下滚动的阅读方式,滚到章尾无缝拼接下一章(类微信读书),与现有翻页模式并存、可切换。
2. **文本高亮标注**:选中正文文本进行高亮,云端同步,跨设备可见,翻页/滚动两种模式均可用。

## 源需求

用户原话:
- "加一个阅读模式,叫做连续阅读,就是类似于上下页的那种"(经确认:上下滚动 + 无缝拼接换章)
- "可以对文本进行一些操作,就是可以高亮什么的"

已确认决策:
- 换章方式:无缝拼接(滚到章尾自动衔接下一章正文)。

## 任务地图

| 子任务 | 交付物 | 顺序 |
| --- | --- | --- |
| `07-26-scroll-reading-mode` | 滚动阅读视口 + 模式切换 + 进度/书签/搜索/目录兼容 | 先做 |
| `07-26-text-highlights` | 高亮的选区交互、渲染、后端存储与同步 | 后做(依赖子任务 1 的偏移映射工具与滚动视口落地) |

## 跨子任务验收标准

- [ ] 两种阅读模式(翻页/滚动)可在设置中自由切换,切换后阅读位置不丢(误差 ≤ 一屏)。
- [ ] 高亮在翻页模式与滚动模式下均正确渲染与可操作。
- [ ] 进度云同步、书签、书内搜索、目录跳转在两种模式下行为一致。
- [ ] PDF 阅读路径完全不受影响。
- [ ] `pnpm -r lint`、`pnpm -r typecheck`、`pnpm -r test` 全部通过。

## 约束

- 遵循现有技术栈:React + Tailwind(web)、Hono + D1(api)、@yudu/shared 共享类型。
- 阅读模式偏好存本地(`useLocalReaderPrefs`),不动后端;高亮存云端(对标 bookmarks 的 D1 + 路由 + 乐观更新 hook 模式)。
- 仅覆盖 txt/md 书籍;PDF 不支持滚动模式与高亮。
