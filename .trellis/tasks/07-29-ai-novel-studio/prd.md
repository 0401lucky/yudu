# AI 小说创作台

## Goal

在雨读中新增一等公民能力 **「AI 小说创作台」**：用户通过完整小说工作流（立项 → 人设 → 总大纲 → 分章细纲 → 逐章正文 → 上架），借助自有 new-api 中转生成作品；支持 **破限模式** 创作成人向（18+）虚构小说；作品可选择是否出现在书架；上架后与创作台为 **同一份内容**，仍可修改与新增章节。

**核心用户价值：** 不是附属小工具，而是可破限的 AI 长篇创作闭环，并与雨读阅读/进度体系打通。

## Background

- 雨读当前主路径为「导入文件 → 解析分章 → 阅读 → 进度同步」，**无「从零创作」入口**。
- 产品定位为通用在线阅读器；本需求是 **新业务线**（小说创作 + 破限），不改变「导入阅读」主路径，但扩展 Book 可写生命周期。
- 用户已自建 new-api，并实测部分模型可稳定生成成人向内容；产品 **不做服务端正文审查**，破限依赖用户自选模型 + 书级模式。
- 硬边界（法律/平台底线）：**禁止任何涉及未成年人的性内容**（角色、描写、暗示均不可）；其余成人向虚构内容为正式支持范围。

## Confirmed Decisions

| 主题 | 决策 |
|------|------|
| 形态 | 完整 AI 小说工作流（方案 C） |
| 破限 | 书级开关 + 账号首次成年确认并记住；服务端不审正文 |
| AI 接入 | 每用户自填 OpenAI 兼容 baseURL / API Key / 模型 |
| 凭证存储 | V1 仅浏览器本地；云端加密同步后置 |
| 调用路径 | 浏览器直连 new-api（需用户中转配置 CORS） |
| 内容存储 | 人设 / 大纲 / 细纲 / 正文全部跟账号上云 |
| 与书架 | 同一 `book` 实体；实时最新稿；导入书仍只读 |
| 上架 | 默认不上架；显式上架/下架；下架保留内容与阅读进度 |
| 编辑 | 纯文本 + 分章列表 |
| AI 正文 | 整章生成 + 流式输出 + 整章重生成 |
| 导航 | 主导航一级「创作台」（如 `/studio`），与书架双向跳转 |
| 架构 | 创作扩展现有 Book（`source=studio`），不另建双实体同步 |

## Requirements

### R1. 创作台入口与列表

- 主导航提供一级入口「创作台」。
- 创作台展示当前用户的创作作品列表（含未上架）。
- 支持新建创作书、进入既有作品的工作流。
- 已上架作品可从书架进入「继续创作」；创作台可「打开阅读」。

### R2. 用户 AI 配置（本地）

- 用户可配置：API Base URL、API Key、默认模型（OpenAI 兼容 Chat Completions）。
- 配置仅存浏览器本地；清除站点数据后需重填。
- 配置缺失时，引导用户填写；不阻塞查看已有云端文稿（仅阻塞 AI 生成类操作）。

### R3. 工作流 V1 步骤

必须按可导航步骤完成（允许前后回看修改，不强制一次线性锁死）：

1. **立项**：书名、类型/基调等基础信息；**破限模式**开关。
2. **人设**：主角/配角卡片（可手写；可 AI 生成后编辑）。
3. **总大纲**：起承转合/分卷大事件（可手写；可 AI 生成后编辑）。
4. **分章细纲**：章节列表与每章节拍/冲突/钩子（可增删改；可 AI 生成后编辑）。
5. **逐章正文**：按细纲对当前章整章流式生成、重生成、纯文本手改。
6. **上架**：显式操作后出现在书架；可下架。

### R4. 破限模式

- 每本书可独立开启/关闭破限。
- 账号首次开启破限（或首次对某书开启破限）时，需确认已成年；确认后账号级记住，不反复弹窗。
- 破限开启时：系统提示词允许成人向虚构内容，并 **明确禁止未成年人相关性内容**。
- 产品 **不对** 章节正文做关键词/分类审查。

### R5. 与书架 / 阅读器同一份作品

- 创作台作品使用与阅读同一套 Book + Chapters 模型（可扩展字段）。
- 上架后阅读器读取的即创作台当前正文；修改或新增章节后再次打开阅读器应为新内容（允许短暂缓存，但需可刷新到最新）。
- 未上架：书架列表不可见。
- 下架：书架不可见；创作台数据保留；阅读进度保留（再上架可续读）。

### R6. 章节与编辑

- 正文为纯文本；UI 为章节列表 + 文本编辑区。
- 支持新增章节（与细纲联动或可随后补细纲）、编辑已有章、保存到云端。
- 导入来源的书籍（txt/md/epub/pdf）**不**进入创作台可写流程（V1）。

### R7. AI 生成行为

- 人设 / 总大纲 / 分章细纲 / 单章正文均可触发 AI 生成（V1 以「生成/重生成」为主，不要求选区改写）。
- 正文生成须支持 **流式** 展示。
- AI 请求由浏览器直连用户配置的 new-api；雨读 API **不**代持 Key、**不**代理模型调用（V1）。

### R8. 安全与合规（产品层）

- 提示与确认文案声明：仅限成年用户；禁止未成年人相关性内容。
- 不实现「假破限」（例如开了开关仍服务端统一拒绝成人向）；是否写得出取决于用户所选模型。

## Out of Scope (V1)

- 世界观独立模块、自动一致性/OOC 检查
- 选区续写/润色、章内多轮对话改稿
- API Key 云端加密同步
- 经 Workers 转发 AI（CORS 不通时的后备方案可另开任务）
- 富文本 / Markdown 创作编辑器
- 将导入书转为可创作书
- 书城、分享发布到公网、多人共创
- 服务端 NSFW 分类或内容审核流水线

## Acceptance Criteria

- [ ] **AC1** 主导航可进入创作台；可新建作品并看到作品列表（含未上架）。
- [ ] **AC2** 用户可在本地保存/修改 new-api 的 baseURL、Key、模型；刷新后仍在（同浏览器未清数据）。
- [ ] **AC3** 可完成立项（含破限开关）→ 人设 → 总大纲 → 分章细纲 → 至少一章正文的云端保存闭环。
- [ ] **AC4** 破限书在用户模型支持的前提下，可流式生成成人向章节正文；首次破限有成年确认且之后同账号不再重复强制确认。
- [ ] **AC5** 未上架作品不出现在书架；上架后出现且可打开阅读器阅读。
- [ ] **AC6** 上架后在创作台修改正文或新增章节，再次进入阅读器可读到更新内容。
- [ ] **AC7** 下架后书架不可见，创作台仍可编辑；再上架后进度仍在（若下架前有进度）。
- [ ] **AC8** 导入书的导入/阅读/进度行为与改造前一致；无法在创作台当作 studio 书编辑。
- [ ] **AC9** 雨读服务端不落库用户 API Key；网络面板可见 AI 请求发往用户配置的 baseURL（直连）。
- [ ] **AC10** 系统提示/确认文案含成年与「禁止未成年人相关性内容」约束。

## Open Questions

无阻塞项。以下为实现期可默认处理、不必再问主人的细节：

- 书架是否展示 18+ 角标：建议 V1 对 `breakLimit` 书显示小标记（实现时写入 design 即可）。
- 细纲与 chapters 索引对齐策略：以细纲顺序生成/对齐 `chapter index`。
- 成年确认存 localStorage 还是用户 preferences：优先 preferences 上云（换设备少弹一次）；若工期紧可先 localStorage。

## Package Scope

- `web`：创作台 UI、本地 AI 配置、直连流式客户端、导航
- `api`：studio 书与设定/章节写 API、上架字段、书架过滤
- `shared`：类型与常量（来源、上架、破限等）
