# 阅读体验增强·第一二梯队

## Goal

一次用户请求包含 5 个可独立交付的功能，本任务为父任务，负责任务地图与最终集成验收。

> 备注：原提案中的「自定义排版」经代码摸底确认已存在（字号/行距/页边距云同步 + 字体/亮度/阅读模式本地设置），不重复实现。

## 任务地图（建议实施顺序）

| 顺序 | 子任务 | 范围 | 复杂度 |
|------|--------|------|--------|
| 1 | 07-27-highlight-notes | 高亮附加笔记 + 笔记汇总页 + 导出 Markdown | 复杂（DB/API/Web 三层） |
| 2 | 07-27-shelf-management | 书架排序、分组、多选批量删除 | 复杂（DB/API/Web 三层） |
| 3 | 07-27-tts-reader | Web Speech API 听书 | 中（纯前端） |
| 4 | 07-27-annual-report | 年度阅读报告页 | 中（API 聚合 + 前端页） |
| 5 | 07-27-quote-card | 书摘分享卡片（Canvas 生成图片） | 中（纯前端） |

依赖说明：quote-card 的入口复用 highlight-notes 的笔记列表，须在其后实施；其余互相独立。
