# 连续阅读(上下滚动)模式

## Goal

在现有横向翻页模式之外,新增"连续阅读"模式:正文上下滚动,滚到章尾自动无缝拼接下一章,阅读体验类似微信读书。用户可在阅读设置中切换两种模式,进度跨模式互通。

## Requirements

### 功能需求

1. **模式切换**:阅读设置面板新增"阅读模式"选项(翻页 / 连续滚动),偏好存本地 localStorage(`useLocalReaderPrefs`),默认翻页(老用户体验不变)。
2. **滚动视口**:
   - 正文垂直滚动,复用现有字号、行距、字体、页边距、主题设置(版心限宽同翻页模式)。
   - 滚到当前章末尾时无缝衔接下一章正文,滚回顶部可回到上一章。
   - 章节间显示轻量分隔(章节标题),让读者感知章节边界。
3. **进度兼容**:
   - 滚动位置实时换算为 `chapterIndex + charOffset`,沿用现有 `useProgressSync.schedule()` 云同步。
   - 打开书时按云端进度恢复到对应滚动位置。
   - 翻页 ↔ 滚动模式互切后,阅读位置偏差不超过一屏。
4. **周边功能对齐**:
   - 底部进度条:展示全书进度,拖动跳转(章 + 章内比例)。
   - 目录/书签/搜索结果跳转:滚动到对应章节与 charOffset 位置。
   - 书签添加/取消:以当前视口顶部位置为锚点,行为与翻页模式一致。
   - 点击屏幕中部唤出/隐藏工具栏;滚动模式下不再有左右点击翻页分区。
   - 键盘 ↑/↓/PageUp/PageDown 走浏览器原生滚动;←/→ 切换上一章/下一章。
5. **页码文案**:滚动模式下底部显示"第 x/y 章 · z%"(章内百分比),不显示页码。

### 非功能需求

- 长章节 + 相邻章拼接不造成明显卡顿;DOM 中最多同时挂载 3 章(当前章 ±1)。
- 调整字号/行距、旋转屏幕后阅读位置基本保持(锚定 charOffset)。

## Out of Scope

- PDF 不支持滚动模式(其设置入口本就关闭)。
- 阅读模式偏好云同步(本地即可)。
- 预取超过相邻一章的内容。

## Acceptance Criteria

- [ ] 设置面板可切换"翻页 / 连续滚动",刷新后偏好保持。
- [ ] 滚动模式下从第 1 章连续滚动可读到最后一章,章节边界有标题分隔、无内容跳变、无明显卡顿。
- [ ] 滚动中进度自动云同步;关掉重开(含用另一模式打开)恢复到同一位置(误差 ≤ 一屏)。
- [ ] 目录、书签、搜索跳转在滚动模式下落点正确;书签图标点亮逻辑与翻页模式一致。
- [ ] 进度条拖动可跳到任意章节位置。
- [ ] 翻页模式回归无差异(现有行为不变),PDF 路径不受影响。
- [ ] `pnpm -r lint && pnpm -r typecheck && pnpm -r test` 通过。
