# 高亮笔记批注与汇总导出

## Goal

读者可以给已有高亮附加文字笔记（想法），并在一个「我的笔记」汇总页按书查看全部高亮与笔记，支持跳转回原文和导出 Markdown。

## Requirements

### 功能需求

1. **写想法**：点击已有高亮弹出的气泡（HighlightPopover）新增「写想法」按钮，打开笔记编辑面板（底部 Sheet），可输入/修改/清空笔记文本；创建高亮的气泡同样提供「高亮并写想法」入口（先创建高亮再打开编辑）。
2. **笔记标识**：带笔记的高亮在正文中以下划虚线（或角标）区别于纯高亮；两种阅读模式一致。
3. **笔记上限**：单条笔记最长 500 字符（前后端同口径校验，常量放 shared）。
4. **标注列表增强**：TocDrawer 的「标注」列表中，带笔记的条目显示笔记预览（截断）。
5. **笔记汇总页**：新路由 `/notes`，按书分组展示当前用户所有高亮（含纯高亮与带笔记的），每条显示摘录、笔记、颜色、时间；点击条目跳转到阅读器对应位置；支持删除条目、编辑笔记；书架页提供入口。
6. **导出 Markdown**：汇总页支持按单本书导出 `.md` 文件（客户端生成下载），格式：书名标题 + 按章节顺序的「> 摘录 / 笔记」列表。
7. **云端同步**：笔记随高亮存 D1，跨设备可见。

### 非功能需求

- 复用现有 highlights 表与路由，新增 note 列，不建新表。
- 汇总页接口一次返回该用户全部高亮（joined 书名），按 book + chapter + offset 排序；无需分页（单书上限 500 条已有约束）。

## Out of Scope

- 独立于高亮的「页面笔记」；PDF 笔记。
- 笔记全文搜索。
- 导出为图片（由 07-27-quote-card 负责）。

## Acceptance Criteria

- [ ] 点击高亮 → 写想法 → 保存后刷新/换设备仍在；正文出现带笔记标识。
- [ ] 笔记超 500 字符前端阻止、后端 400。
- [ ] `/notes` 页按书分组展示、可跳转、可编辑/删除；空状态友好。
- [ ] 导出的 Markdown 文件内容正确、按章节排序。
- [ ] 越权（他人书）404；highlights 路由测试补充 note 相关用例。
- [ ] `pnpm typecheck && pnpm test` 通过。
