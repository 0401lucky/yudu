# 产品定位 — 雨读（Yudu）

> **给所有对接本仓库的 AI / 开发者的权威定位说明。**  
> 改文案、加格式、写 PRD 前先读本文件；与历史「小说阅读器」文档冲突时，**以本文件为准**。

**最后更新：** 2026-07-20

---

## 一句话

**雨读**是部署在 Cloudflare 上的 **通用在线阅读器**：账号云同步、导入多格式文档、沉浸式左右翻页阅读。

品牌气质仍可保留「雨夜书房」的安静视觉，但**业务范围不限于小说**。

---

## 是 / 不是

| 是 | 不是 |
|----|------|
| 个人文库 / 文档 / 笔记 / 电子书的云端阅读 | 网文站、书城、版权分发 |
| 多格式阅读客户端（Web） | 在线协同编辑器 |
| 进度与偏好按用户隔离同步 | 社交、评论、推荐流 |
| 可扩展格式（解析器注册表） | 仅「长篇小说」单一场景 |

历史文档（如 `docs/superpowers/specs/2026-07-11-novel-reader-design.md`）描述的是**早期小说向 MVP**；架构与 Cloudflare 部署方案仍有效，**产品边界以本文件为准**。

## 内容类型（当前与路线图）

### 当前支持（`SUPPORTED_FORMATS`）

| 格式 | 说明 |
|------|------|
| `txt` | 纯文本；编码 UTF-8 / 常见中文编码 |
| `md` | Markdown；GFM 阅读渲染；可按标题分章；支持重新解析 |
| `epub` | EPUB；提纯正文为可读文本流 |

领域模型仍用 **Book / 书** 表示「一部可阅读作品」（笔记合集、手册、小说均可），**不是**「只能是虚构故事」。

### 已预留、尚未实现

| 格式 | 状态 |
|------|------|
| `pdf` | `BookFormat` 联合类型已含 `"pdf"`；**无解析器、无导入入口**；后续任务再做 |

### 明确不做（除非新 PRD）

- 书城 / 发现页 / 版权交易  
- 多人共享书架  
- 富文本在线编辑源文件

## 核心用户旅程（不变）

```
注册登录 → 书架导入文件 → 解析分章入库 → 阅读器左右翻页 → 进度/偏好云同步
```

技术栈速记：

```
@yudu/web (Vite SPA)  ──/api──►  @yudu/api (Workers + Hono)
        │                              │
        └──────── @yudu/shared ────────┘
                       D1 元数据 · R2 正文/封面/源文件
```

---

## 扩展新格式时（如 PDF）AI 必做清单

1. **shared**：`SUPPORTED_FORMATS` / `BookFormat`（pdf 已在类型中时可只放开白名单）。  
2. **api/parsers**：新 `parsers/<fmt>.ts` + 测试 + fixtures；输出统一 `ParseResult`（章节 `title` + `text` 或未来富内容契约）。  
3. **importBook**：`detectFormat` / `parseByFormat` / MIME。  
4. **web**：`ImportDropzone` 的 `ACCEPT` 与提示文案。  
5. **阅读器**：若 PDF 需要非纯文本/非 MD 路径，扩展 `ReaderViewport` 的 `contentMode`（或等价），**勿**把二进制塞进现有 plain 字符串硬渲染。  
6. **spec**：更新本文件「当前支持」表 + `api/backend` 解析器目录说明。  
7. **安全**：外链、HTML、PDF 脚本面；禁止未消毒 `dangerouslySetInnerHTML`。

## 文案与域语言建议

| 场景 | 推荐 | 避免 |
|------|------|------|
| 产品一句话 | 通用阅读器 / 云端文库阅读 | 「仅小说阅读器」作为唯一定位 |
| 导入对象 | 书籍 / 文档 / 作品 | 暗示只能网文 |
| 空状态 | 导入第一份文档 | 「打开一本小说」唯一说法 |
| 格式列表 | 写清当前格式 +「更多格式规划中」 | 写死「永远只有三种」 |

保留可用：书架、章节、书签、进度——通用阅读器同样适用。
